# AI Engineering Training

Personal workspace for the AI Engineering Training Plan — an 8–12 week, 10-phase roadmap (Phase 0–9) taking a zero-AI-background engineer to the point of reading company architectures, understanding workflows, and implementing real tasks with Claude Code.

Full narrative detail: [`guidance.md`](./guidance.md) and `AI-Engineering-Training-Plan 1 4.pdf`.

## Core Philosophy

1. **Build to learn** — every phase ends with a concrete "prove it" build/checkpoint, not just reading/watching.
2. **Specify before you generate** — sketch a 1-paragraph architecture/plan before asking Claude Code to generate code.
3. **Own correctness** — Claude Code writes code; the engineer owns whether the architecture, plan, and code are actually correct.
